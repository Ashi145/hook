# Hook - Viral Music Discovery & Distribution

**Hook** is a next-generation music discovery and distribution platform designed for the viral age. Built as a sleek, mobile-first web application, it bridges the gap between discovering trending sounds and creating the next big hit.

## Core Experience
At the heart of the application is the **Trending Dashboard**, a dynamic feed showcasing "Viral Now" tracks with real-time growth metrics (e.g., "+400%"). Users can instantly preview songs, view artist details, and see cross-platform performance data. The interface utilizes a modern glassmorphism aesthetic with neon accents, fully optimized for a premium dark-mode experience.

## Creator Tools
Hook empowers artists with robust distribution capabilities. The **Add Music** portal streamlines the release process, allowing creators to upload tracks, input metadata, and select distribution targets—including Spotify, Apple Music, TikTok, and YouTube Music—all from a single screen.

## Discovery & Insights
Powered by the **YouTube Data API**, the **Search** feature allows users to instantly find and analyze tracks. The dedicated **Stats** page provides artists with actionable insights, visualizing total streams, audience growth, and top regions.

## Personalization
The enhanced **User Profile** offers deep customization. Users can manage their brand identity, link social media accounts (TikTok, Instagram), toggle between themes, and set music genre preferences to tailor their feed. Integrated sharing functionality ensures that profiles and tracks can be easily broadcast to external networks.

Whether you are a listener hunting for the next earworm or an artist looking to break through the noise, Hook provides the ecosystem to make hits happen.
